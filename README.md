# Discuzz

Discuzz is a PHP and MySQL-based platform that allows users to log in, ask questions, answer questions from other users, delete their own questions, and search for the latest questions or their own. The project is designed to facilitate a community-driven question-and-answer experience.

## Features

- **User Login**: Users can log in to the platform to access features.
- **Ask Questions**: Logged-in users can post their questions for others to answer.
- **Answer Questions**: Users can respond to questions posted by other users.
- **Delete Questions**: Users can delete their own questions.
- **Search**: Users can search for the latest questions or filter questions by their own submissions.
- **Responsive Design**: The platform is currently responsive for laptop screens.

## Technologies Used

- **PHP**: Server-side scripting language for handling the business logic.
- **MySQL**: Database used to store user data, questions, and answers.
- **HTML/CSS**: Frontend technologies for structuring and styling the web pages.
